          救机

          救机说明

          刷修改版之前请读完。出问题时，可以尝试用官方 GR III 2.10 原件刷回去。本工具生成的文件不会把版本号调高：版本字段保持 2.10。同一版本可以重复更新：已在一台 GR III 上实测，改过的 2.10 可以刷入 2.10 机身，也可以再刷回官方 2.10 原件。每一份文件还过了“救机门禁”：引导链记录、RTOS/ICONBIN/RES 以外的记录，以及更新器与开机流程所在的两个代码区域，都和原件逐字节相同，否则不会提供下载。门禁只是这几条已列规则的离线检查，不覆盖其余改动的影响，也不保证刷回一定成功。

          出问题时怎么判断

          相机拒收修改版（File Broken / Update Failure，没见到更新进度）
          按代码分析，这类拒收发生在写入之前（未在实机验证），也不能证明机身此前完好。先别删文件：核对卡上文件的 SHA-256 与构建清单一致，记下屏幕信息，再照常开机检查各项功能
          能开机，但显示或颜色不对
          可以尝试刷官方 2.10。进得了更新画面不代表一定成功，刷完逐项核对
          开机卡住，但还能进更新画面
          同上，可以按下面步骤尝试
          完全开不了机 / 刷到一半断电
          先满电、插救机卡、按住 MENU 键开机，看能不能见到更新画面。见到了：可以按下面的步骤尝试，结果不能事先保证。见不到更新画面：目前没有已验证的用户恢复方法，停手，记下刷的文件和出事时的进度，联系售后

          准备救机卡（刷机前做好）

          1. 准备一张单独的 SD 卡，平时不拍照用。
          2. 在相机里格式化这张卡。
          3. 把官方 fwdc239b.bin 复制到卡的根目录，文件名不改，不放进文件夹。
          4. 把卡上的这个文件拖到下面，核对它是不是官方原件。
          5. 和充满电的备用电池放在一起。

          刷机前

          1. 把影像控制及其详细设置、U1–U3、按键设置拍照记下来，刷机后设置可能被重置。
          2. 电池充满，或接 AC 适配器。
          3. 有备用机的话，先在备用机上测。

          救机步骤

          1. 插入救机卡，按住 MENU 键再开机，进入固件更新画面后按提示确认。
          2. 更新中不要关机、不要开电池仓、不要拔卡。整个更新过程都不能断电；按代码分析，引导链在最后阶段才写入。
          3. 出现 Update failed：关机，再开机重试一次；还失败就停下，拍下屏幕信息。
